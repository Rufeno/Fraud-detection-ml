# 🔐 Fraud Detection ML

Sistema de detecção de fraudes bancárias utilizando Machine Learning.

---

# 📌 Sobre o projeto

Este projeto foi desenvolvido como Trabalho de Conclusão de Curso (TCC) com o objetivo de identificar transações bancárias fraudulentas utilizando técnicas de Machine Learning.

O sistema analisa padrões em transações financeiras e busca detectar comportamentos suspeitos de forma automatizada, auxiliando na prevenção de fraudes.

---

# 🚀 Tecnologias utilizadas

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Jupyter Notebook

---

# 🧠 Modelos utilizados

* Logistic Regression
* Decision Tree
* Random Forest

---

# 📊 Resultados

O projeto busca identificar fraudes em meio a grandes volumes de transações financeiras.

Métricas utilizadas:

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC

# ▶️ Como executar

## 1. Clone o repositório

```bash
git clone https://github.com/Rufeno/Fraud-detection-ml.git
```

## 2. Entre na pasta

```bash
cd Fraud-detection-ml
```

## 3. Instale as dependências

```bash
pip install -r requirements.txt
```

## 4. Execute o notebook

Abra o Jupyter Notebook:

```bash
jupyter notebook
```
